# Teach the Machine / علّم الآلة

This is a placeholder interactive visualization for Byte 0.

## Purpose

The learner should feel that AI improves when it receives more examples.

The interaction should show:

1. The learner gives examples.
2. The machine makes a guess.
3. The learner adds more examples.
4. The machine's confidence or accuracy changes.

## Language

Default language: Arabic
Direction: RTL
Secondary language: English

## Files

- `config.json` controls the examples, labels, rounds, and UI options.
- Media paths are relative to this folder unless otherwise handled by the platform.
